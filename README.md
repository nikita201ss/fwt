# Запуск проекта React + TypeScript + Vite

1. Клонируем репозиторий с проектом удобным способом (например по https)
  ```
  git clone https://github.com/nikita201ss/fwt.git
  ```

2. Переходим в директорию
   ```
  cd fwt
   ```

3. Устанавливаем зависимости (node.js должен быть версии 20.19+ или 22.12+)
  ```
  npm install
  ```

4. Запуск проекта
  ```
  npm run dev
  ```
